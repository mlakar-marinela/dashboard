## DESCRIPTION

This project represents a financial dashboard where the user can see their overall financial performance.

The app was made with: HTML, CSS, TypeScript, Redux Toolkit, Chart.js, React, Vite, Vitest.

Key functionalities:

- storing data from forms. Before viewing the financial charts, the user must input 3 years of financial data in a form (the form has 3 fields: year, turnover and profit). For each submission, all the present data will be stored in specific objects.

- dynamic chart viewing. Based on the data entered in the form, 4 charts will be displayed: 2 for the turnover analysis and 2 for the profit analysis.

- dynamic scoring. Based on the financial data entered in the form, a company score will be displayed using 3 years of profit and turnover.

- responsive UI. The entire content of the dashboard fits acording to any screen width.
