This project represents a financial dashboard where the user can see their overall financial performance.<br/>
<br/>
The app was made with:<br/>
<br/>
-HTML<br/>
<br/>
-CSS<br/>
<br/>  
-TypeScript<br/>
<br/>
-Redux</br>
</br>
-Chart.js<br/>
<br/>  
-REACT<br/>
<br/>
-VITE<br/>
<br/>
Key functionalities:<br/>
<br/>
-Storing data from forms. Before viewing the financial charts, the user must input 3 years of financial data in a form (the form has 3 fields: year, turnover and profit). For each submission, all the present data will be stored in specific objects.</br>
<br/>
-Dynamic chart viewing. Based on the data entered in the form, 4 charts will be displayed: 2 for the turnover analysis and 2 for the profit analisys.<br/>
<br/>
-Dynamic scoring. Based on the financial data entered in the form, a company score will be displayed using 3 years of profit and turnover</br>
</br>
-Responsive UI. The entire content of the dashboard fits acording to any screen width.</br>
